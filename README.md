# NVIDIA 台灣合作夥伴概念股動態分析報告

本專案提供全台 70+ 家 NVIDIA 供應鏈與合作夥伴概念股的即時數據分析、歷史走勢圖表與市場動態報告。

## 🌟 專案亮點

- **完整涵蓋台廠供應鏈**：包含晶片製造與先進封裝、AI 伺服器與系統代工、機器人與邊緣 AI、電源散熱關鍵零組件、顯卡板卡等各大板塊。
- **動態走勢視覺化**：整合歷史 65 日股價走勢圖、多股對比分析圖與 LED 買賣訊號條。
- **雲端自動化更新**：透過 GitHub Actions 於每個交易日收盤後自動抓取最新股市數據並重新渲染報告，無需維護任何雲端伺服器。

## ⚙️ 自動化機制

本專案已配置 GitHub Actions 工作流。每個交易日台灣時間 15:30，系統會自動抓取最新市場數據並更新網頁，讓您輕鬆掌握最新的合作夥伴概念股動態。
